# 嘎嘎香 乐山油炸串串 · 微信小程序

一个微信小程序配送点单项目：菜单展示、菜品分类筛选、最近点过推荐、商品数量加减、购物车明细弹层、商品详情、售罄状态、结算下单（配送地址、配送费、新人首单满 50 减 5）、订单列表（删除/清空、再来一单），以及一个「我的」页：微信登录、头像昵称、历史订单和下单总额、我的优惠券、门店信息、商家入口。商家入口包含**订单管理**（自动检查新订单、声音/震动提醒、接单、开始配送、完成、取消并退回优惠券）、**菜品管理**（改价、上新、售罄、上下架、从本地导入菜单）和**优惠券管理**（模板、启停、发放）。本地可以浏览菜单；**正式提交订单需要开通云开发**。当前为线下收款模式：顾客提交订单，商家接单后电话确认金额和付款方式。界面使用 Vant Weapp 组件库。

> 已额外完成 H5 点单站 + 商家后台，并部署到 Cloudflare 免费 Worker。
> 正式点单地址：https://xaingdepibao.icu/
> 商家后台：https://xaingdepibao.icu/admin
> 商家操作、费用和验收记录见 [正式上线说明.md](正式上线说明.md)。

- 正式接单需要云开发；订单、openid、收货地址、菜单和优惠券会跨设备同步
- 订单金额由云函数按数据库里的菜品重新计算，客户端改价无效
- 商家可在小程序里处理订单、管理菜品、发券
- 订单页每 15 秒自动检查新订单，有新单时震动、播放提示音并显示横幅
- 所有代码带中文注释
- 适合完全新手边跑边学

## 快速开始

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 导入本文件夹 `D:\ai\油炸小程序`
3. 填入你自己的小程序 AppID；只浏览菜单可以不接云开发，但**提交订单必须配置云开发**
4. 点菜单栏「工具 → 构建 npm」（第一次必须做）
5. 运行后从底部 tab 进入「我的」，体验微信登录、历史订单统计和门店信息

详细步骤、文件说明、练习和常见问题见 [学习指南.md](学习指南.md)。

## 云开发（可选）

默认不配置云环境也能浏览菜单；要正式接单、同步订单和菜单：

1. 用你自己的 AppID 在开发者工具里开通「云开发」并创建环境
2. 把环境 ID 填到 `miniprogram/envList.js` 的 `envList`，例如 `['cloud1-xxxxxxxx']`
3. 云函数首次登录会自动创建 `orders`、`addresses`、`coupons`、`userCoupons`、`users`、`config`、`dishes` 集合，并写入默认的「新人首单券」；菜单需要在「菜品管理」里点一次「导入本地菜单」
4. 右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」
5. 重新编译。云函数不可用时，菜单会回退到本地，但下单会被拦截并提示联系商家

数据库权限建议把 `orders`、`addresses`、`coupons`、`userCoupons`、`users`、`config`、`dishes` 都设为「**所有用户不可读写**」，统一由云函数访问，避免顾客直接读取别人的订单和地址。

### 商家订单管理

1. 打开小程序 →「我的」→ 页面底部「商家入口」
2. 首次进入会显示当前用户 openid；到云开发控制台 → 数据库 → `config` 集合 → `admin` 文档，把这个 openid 加到 `openids` 数组
3. 重新进入「商家入口」，就能看到所有顾客的订单

配置好管理员后，商家入口只会对 `openids` 名单里的账号显示；还没有配置任何管理员时，入口对登录用户可见，方便第一次配置。

订单流程：**待接单 → 制作中 → 配送中 → 已完成**。商家可以接单、开始配送、完成订单；在待接单/制作中/配送中阶段也可以取消订单。取消后如果顾客用了优惠券，券会自动退回。

商家订单页打开时每 15 秒自动检查一次新订单：有新的待接单订单会震动、播放提示音并在页面顶部显示提醒条，也可以点「测试提醒」试听。离开订单页后停止检查；小程序关闭时不会提醒，那种场景需要微信订阅消息。

### 商家菜品管理

在订单管理页点右上角「菜品」进入。

1. 第一次进入时，点「导入本地菜单」把 `goods.js` 里的 47 道菜写进云数据库
2. 之后可以直接修改名称、分类、价格、单位、描述、标签和图标
3. 每道菜可以一键标「售罄 / 恢复」或「下架 / 上架」
4. 新增的菜品会自动排在菜单后面

顾客端会优先读取云端菜单；云端还没有导入时，继续使用本地 `goods.js` 兜底。菜品管理依赖云开发。

### 商家发券

在订单管理页点右上角「优惠券」进入。可以新建、编辑、停用优惠券，也可以发给指定用户或全部用户。

默认规则：新用户没有下过单时，自动获得一张「新人首单券」，满 50 减 5，仅限首单使用。商家可以改门槛、改优惠金额，也可以停用或新建其他券。

门店配置、昵称和头像仍保存在本地；云端菜单导入前使用本地 `goods.js`。云开发不包含微信支付和实际配送调度。启用云开发后，之前本地模式下的订单不会自动迁移到云端，会继续留在本机。

## 正式使用前

- **下单强依赖云开发**：`app.js` 的 `requireCloudForOrders` 默认为 `true`，云服务不可用时不允许下单，避免订单只存在顾客手机里、商家收不到。只做本地演示时可以改成 `false`。
- **金额以服务端为准**：云函数会按 `dishes` 集合里的当前价格和 `config/store` 里的配送费重新计算商品金额、配送费和订单金额，客户端传的价格和总额不会被采用。
- **配送费配置有两处**：客户端展示用 `app.js` 的 `store`，服务端结算用云数据库 `config` 集合的 `store` 文档。修改配送费时两处要一起改。
- **数据库权限**：所有集合设为「所有用户不可读写」，只允许云函数访问。
- **支付与合规**：当前不接在线支付，结算页和下单成功页会提示「线下支付，商家接单后电话确认」。在线支付需要微信支付商户号；小程序备案、餐饮/食品经营资质、隐私协议需要你本人办理。
- **新订单提醒**：仅在商家订单页打开时有效；小程序关闭或在后台时需要接入微信订阅消息。
- **正式上线前**：用两个微信号在真机上完整走一遍下单、接单、配送、完成、取消退券、改价和售罄流程。
